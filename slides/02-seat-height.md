## Lower the seat height

- Adventure motorcyclists say it to nervous riders: **get your feet on the ground first**
- 3D looks hard because the demos you see are huge
- Today: four small files, one new idea each
- Plain HTML and JavaScript. No framework, no build step
- If you can write a web page, you can do this

???

The motorbike line is the point of the whole talk. A tall adventure bike is terrifying until
you lower the seat and both feet touch the ground. Then you can learn to ride.

Every workbook is one HTML file of about 200 lines, with the same four sections. View source
is the documentation.
