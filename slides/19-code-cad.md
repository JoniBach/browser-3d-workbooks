## Shapes from code

- **CAD**: computer-aided design, for things that get made
- Most CAD is clicking. **Code CAD** describes the shape in a program instead
- **JSCAD** does it in JavaScript (inspired by OpenSCAD)
- Change a number, get a new design: **parametric** design
- Everything is in **millimetres**, ready for a 3D printer

???

Why code? Because a design becomes repeatable and adjustable: one slider changes the diameter
and everything else follows. And it lives in git like any other code.
